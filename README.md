# Janela SDL3 em C++

Um programa simples em C++ que abre uma janela preta usando SDL3 e mostra a posição do mouse no título da janela.

## Compilar

```powershell
C:\msys64\ucrt64\bin\g++.exe hello.cpp -o hello.exe -mwindows -IC:\msys64\ucrt64\include -LC:\msys64\ucrt64\lib -lSDL3
```

## Executar

```powershell
.\hello.exe
```
